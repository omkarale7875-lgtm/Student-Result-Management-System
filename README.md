# Student Result Management System

A desktop-based Student Result Management System built using Python Tkinter and Microsoft SQL Server.

## 🚀 Features

- Professional Dashboard
- Student Management
- Add Student
- Update Student
- Delete Student
- Student Result Management
- Result Analytics
- Grade Distribution
- Course Management
- Database Connection Status
- Settings Page
- Dark Enterprise UI

## 🛠️ Technologies Used

- Python
- Tkinter
- Microsoft SQL Server
- PyODBC
- SQL
- ttk
